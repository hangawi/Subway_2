- 휴대폰 **Chrome(안드로이드) 또는 Safari(iPhone)** 로 열어요. 카카오톡 안 브라우저에서는 마이크가 되는지 아직 확인하지 않았어요.

## 2. 장소로 매장·메뉴 찾기

## 3. 주문할 매장 바꾸기

1. 매장 칸의 **[다른 매장 더 보기]** 를 눌러요.
2. 두 번째 매장의 **[이 매장으로 주문]** 을 눌러요.

→ "✓ 주문할 매장" 표시가 두 번째 매장으로 옮겨가요.
→ 첫 매장에는 [이 매장으로 주문] 버튼이 다시 생겨요. 세 버튼([이 매장으로 주문]·[전화]·[길찾기])은 한 줄, 같은 높이예요.

결과: 성공 / 실패 / 미확인

## 4. [확인]을 누르기 전에는 아무것도 안 나감

1. 1번 메뉴의 **[담기]** 를 눌러요.
2. 옵션에서 아무거나 하나 바꿔요(예: 소스 하나).
3. 주문서 아래 **[이대로 주문하기]** 를 눌러요.

→ 노란 칸에 **"(매장 이름)에 이 주문서로 주문할까요?"** 가 보여요.
→ "앱이 매장에 직접 보내지 않아요. 확인하면 내 주문에 기록되고…" 문구와 **[다시 고르기] [확인]** 만 보여요.
→ 이때는 주문서 글·복사·전화 버튼이 **아직 없어요**.

4. **[다시 고르기]** 를 눌러요.

→ 다시 [이대로 주문하기] 버튼만 남아요.

결과: 성공 / 실패 / 미확인

→ "복사했어요. 매장 직원에게 보여 주거나 붙여 넣으세요"가 보여요.
→ 붙여 넣은 글이 화면의 주문서 글과 같아요.

## 9. 다시 주문 · 지우기 · 전부 지우기

1. 메뉴를 하나 더 골라 [이대로 주문하기] → [확인]으로 기록을 하나 더 만들어요.

→ "내 주문"에 2개가 보이고, 최근 것이 위에 있어요.

2. 아래쪽 기록의 **[다시 주문]** 을 눌러요.

→ 4 옵션 고르기로 올라가고, 그 메뉴와 그때 고른 옵션이 그대로 들어가 있어요.

3. 기록 하나의 **[지우기]** 를 눌러요.

→ 그 기록만 사라지고 1개가 남아요.

4. **[전부 지우기]** 를 누르고 확인 창에서 확인을 눌러요.

→ "아직 기록이 없어요…" 문구만 남아요.

결과: 성공 / 실패 / 미확인

## 10. 주문 기록 동의를 끄면 저장 안 됨

1. 기록을 하나 만든 뒤(8번처럼), 맨 아래 **"내 정보 (동의·기록)"** 를 열어요.
2. **주문 기록 저장** 을 꺼요.

→ "내 주문" 칸이 통째로 사라져요(기록도 지워져요).

3. 메뉴를 고르고 **[이대로 주문하기] → [확인]** 을 눌러요.

→ **"주문 기록 저장을 꺼 두셔서 기록하지 않았어요. 아래 "내 정보"에서 켤 수 있어요"** 가 보여요.

4. "내 정보"에서 **주문 기록 저장** 을 다시 켜요.

→ "내 주문" 칸이 다시 보이지만 **비어 있어요**(지운 기록은 돌아오지 않아요).

## 11. 알레르기는 따로 동의해야 기억

1. ② 메뉴 주문의 **알레르기** 칸(초록 테두리 막대)을 열고 **우유** 를 눌러요. (아직 "알레르기 기억하기"는 꺼져 있어요)
2. 새로고침해요.

→ 알레르기 옆에 "(우유)"가 **없어요**(동의 안 하면 그 자리에서만 써요).

3. "내 정보"에서 **알레르기 기억하기** 를 켜고, 다시 **우유** 를 고른 뒤 새로고침해요.

→ "알레르기 (우유)"가 **그대로 남아 있어요**.

4. **알레르기 기억하기** 를 끄고 새로고침해요.

→ "(우유)"가 사라져요.

결과: 성공 / 실패 / 미확인

## 12. 알레르기 든 재료 표시 · 경고

1. ② 메뉴 주문의 **알레르기** 에서 **우유** 를 골라요.
2. 조건에서 **샌드위치** 를 누르고, 메뉴 하나의 **[담기]** 를 눌러요.

→ 옵션의 치즈 **아메리칸·슈레드·모차렐라** 버튼이 **연한 빨간 바탕**이고 아래에 **"우유 들어 있음"** 이 보여요.
→ 빵 **파마산 오레가노·플랫브레드** 도 "우유 들어 있음", 나머지 빵은 **"우유 ★"** 가 보여요.
→ 주문서 위에 **노란 경고** "⚠ 고른 알레르기 우유가 들어 있을 수 있어요 (★)…"가 보여요(위트빵 ★).

3. 치즈에서 **아메리칸 치즈** 를 눌러요.

→ 버튼은 눌려요(막지 않아요).
→ 주문서 위에 **빨간 경고** "⚠ 고른 알레르기 우유가 들어 있어요. 메뉴나 재료를 바꿔 주세요"가 보여요.

4. **[이대로 주문하기] → [확인]** 을 눌러요.

→ 주문서 글 맨 아래에 **"※ 우유 알레르기가 있어요. 재료 확인 부탁드려요"** 가 있어요.

5. 치즈를 다시 **없음** 으로 바꿔요.

→ 빨간 경고가 노란 경고로 바뀌어요.

결과: 성공 / 실패 / 미확인

## 15. 🎤 말로 입력 (🆕 10/26: 휴대폰 받아쓰기 먼저)

> 안드로이드 Chrome·아이폰 Safari는 **휴대폰 받아쓰기**, 카카오톡 안 브라우저처럼 안 되는 곳은 **OpenAI**로 받아써요. 아래 [취향 그래프] → 말 기록에 "🎤 말 (휴대폰 받아쓰기)" 또는 "(OpenAI 받아쓰기)"로 보여요. **세 곳에서 각각** 해 봐 주세요.

→ 처음이면 휴대폰이 **마이크 허용** 을 물어요 → **허용** 을 눌러요.
→ 🎤 가 **빨갛게 깜빡이고** "듣고 있어요… 말을 멈추면 2초 뒤 저절로 보내요. 바로 보내려면 [보내기]"가 보여요. (10/22)

→ 8초쯤 뒤 **저절로 끝나요**(빨간 깜빡임이 멈춰요). "알아듣지 못했어요…" 안내가 떠도 괜찮아요.

5. 아래 **[취향 그래프]** 탭 → **말 기록** 에 방금 한 말이 시각·"🎤 말"·알아들은 것·처리한 곳(규칙 / GPU / OpenAI)과 함께 보여요.
