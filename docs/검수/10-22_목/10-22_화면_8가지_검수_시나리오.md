## 단계별

### 1. 이름 "현재 위치로 찾기" (요청 6)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ① 매장의 초록 버튼을 봄 | 버튼 글자가 **현재 위치로 찾기** ("지금 위치로 찾기"가 아님) | |

### 2. 처음엔 ③ 추천이 접혀 있음 (요청 2)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 위치가 잡힐 때까지 기다린 뒤 ③ 추천 메뉴로 내려감 | 메뉴 카드는 안 보이고 **"② 메뉴 주문에서 말하거나 조건을 고르면 추천해요"** 안내와 [조건 없이 추천 보기] 버튼만 보임 | |
| (다른 탭에서) [조건 없이 추천 보기]를 누름 | 그 자리에서 Top3 메뉴 카드가 펼쳐짐 | |

> 2-2는 새 시크릿 탭으로 따로 해요. 이 탭은 접힌 채로 다음 단계로 가요.

### 3. 매장 카드 버튼 한 줄 (요청 5)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ① 매장의 첫 매장 카드를 봄 | **[✓ 주문할 매장] [전화] [길찾기]** 가 한 줄에, 같은 높이·같은 모서리로 나란히 있음 (두 줄로 넘어가지 않음) | |
| [전화]·[길찾기]가 버튼 모양인지 봄 | 밑줄 글자가 아니라 초록 테두리 버튼 | |
| 매장이 여러 곳이면 [다른 매장 더 보기]를 누름 | 다른 매장 카드에는 진한 초록 **[이 매장으로 주문]** 버튼 (밑줄 글자 아님), 버튼이 한 줄 | |
| 다른 매장의 [이 매장으로 주문]을 누름 | 그 카드가 "✓ 주문할 매장"으로, 처음 카드는 [이 매장으로 주문]으로 바뀜 | |

### 3-2. 비교 열고 닫기 (10/22 추가)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ③이 펼쳐진 뒤 [1번이랑 2번 비교]를 누름 | 비교 내용이 열리고 버튼이 **[비교 닫기]**로 바뀜 | |
| [비교 닫기]를 누름 | 비교 내용이 닫히고 버튼이 다시 [1번이랑 2번 비교] | |

### 3-3. 주문은 [확인]에서 끝 (10/22 추가)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 메뉴를 고른 뒤 ⑤에서 [이대로 주문하기] → [확인] | 주문서 글·[주문서 복사]·전화·길찾기가 나오고, **[이걸로 주문했어요] 버튼은 없음** | |
| 같은 자리를 봄 | 주문 기록 동의가 켜져 있으면 "내 주문에 기록했어요 (이 휴대폰에만)", 아래 "내 주문"에 바로 1개. 꺼져 있으면 "기록하지 않았어요" 안내 | |
| [이대로 주문하기] → [다시 고르기] | 기록되지 않음 ("내 주문" 개수 그대로) | |

### 4. 🎤가 ② 보내기 옆 (요청 4)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ① 매장 제목 옆을 봄 | 🎤가 **없음** | |
| ② 메뉴 주문의 입력 칸을 봄 | **[입력 칸] [🎤] [보내기]** 순서로 한 줄 (🎤는 음성 기능이 켜진 휴대폰에서만 보여요. 안 보이면 "미확인"으로 적어요) | |

### 5. 잘 보이는 버튼들 (요청 4 · 8)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ② 메뉴 주문의 **알레르기** 칸을 봄 | 초록 테두리 막대 + 오른쪽에 "열기 ▾" | |
| 알레르기를 누름 | 펼쳐지고 "닫기 ▴"로 바뀜. 우유를 고르면 막대에 노란 숫자 배지 | |
| (알레르기를 고른 상태라면) ③의 **뺀 메뉴** 칸을 봄 | 알레르기와 같은 테두리 막대 모양 | |

### 6. 음료·사이드만이면 ③ 잠김 (요청 1)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ② 맨 아래 [샌드위치 없이 음료·사이드만]을 누름 | ④에 음료·사이드 고르기가 열림 | |
| ③ 추천 메뉴로 올라가서 [담기]나 [Why?]를 눌러 봄 | **아무 반응 없음** (회색으로 흐려져 있고 눌리지 않음). 제목 옆에 "음료·사이드만 고르는 중" | |
| ③ 위쪽을 봄 | 또렷한 [샌드위치 고르기로 돌아가기] 버튼 하나만 보임 | |

### 7. 마지막 음료를 −로 빼기 (요청 3)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ④에서 음료 하나(예: 콜라)를 누름 | ⑤ 주문서에 그 음료가 들어감, ④에 "콜라 × 1 [−] [+]" | |
| [−]를 누름 | 음료가 빠지고 ⑤에 **"아직 담은 음료·사이드가 없어요. ④에서 고르면 주문서가 생겨요"** (예전처럼 다시 들어가지 않음) | |
| 다시 음료를 누른 뒤, 이번엔 음료 버튼을 한 번 더 눌러 뺌 | 똑같이 비워지고 같은 안내 | |

### 8. 샌드위치 고르기로 돌아가기 (요청 1)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ③의 [샌드위치 고르기로 돌아가기]를 누름 | 화면이 ③으로 가고, 회색이 풀리고, Top3 메뉴 카드가 보임 (처음에 접혀 있었어도 펼쳐짐) | |
| [담기]를 눌러 봄 | 눌리고 ④ 옵션 고르기로 감 | |

### 9. 보내기 → ③으로 이동 (요청 4)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 새로고침 → ② 입력 칸에 `매운 걸로 추천해줘` → [보내기] | ③이 펼쳐지고 **화면이 ③ 추천 메뉴로 내려감**. 맨 위 메뉴가 매운 메뉴 | |
| ③에서 아무 메뉴나 [담기] → 다시 ②에 `가볍게` → [보내기] | 고른 메뉴는 그대로, 화면은 바뀐 ③으로 감 | |

### 10. 장소를 말하면 → ①로 이동 (요청 4)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ②에 `역삼역에서 먹을래` → [보내기] | **화면이 ① 매장으로 올라감**, 역삼역 근처 매장이 나옴 | |
| ②에 `강남역` → [보내기] (여러 곳인 장소) | 화면이 ①로 가고 "어느 곳인가요?" 고르기 목록, ②에 "여러 곳이에요. 위에서 고르면 이어서 추천해요" | |
| 목록에서 하나 고름 | 매장과 추천이 이어서 나옴 | |

### 11. 아직 안 고른 것 알림 (요청 7)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 새로고침 → `매운 거` 보내기 → ③에서 [담기] (빵·소스는 건드리지 않음) | ⑤ 주문서 위에 노란 칸 **"아직 안 고른 것"** — 빵 (지금은 ○○), 소스 (안 고르면 소스 없이) | |
| 노란 칸 아래를 봄 | 주문서(금액·열량)는 그대로 있고 [이대로 주문하기]도 누를 수 있음 — **막지 않고 알려만 줌** | |
| ④에서 소스 하나를 고름 | 노란 칸에서 "소스"가 사라짐 | |
| ④에서 빵을 고름 | 빵도 사라지고, 다 고르면 노란 칸이 없어짐 | |
| ④에서 세트(예: 쿠키 음료 세트)를 고르고 쿠키·음료는 안 고름 | 노란 칸에 "세트 구성품"·"세트 음료"가 나옴 | |

> 소스를 늘 고르던 메뉴는 "평소처럼"이 자동으로 채워 줘서 소스가 안 나올 수 있어요 (시크릿 탭이면 기록이 없어 나와요).
