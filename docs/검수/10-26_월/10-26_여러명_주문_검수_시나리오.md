# 10/26 장바구니·여러 명 주문 검수 시나리오

> 주소 **https://subway.metasolveai.com** · 10/26 오후 장바구니 방식 (배민처럼) · 자동 점검: `scripts/cart-check.ts`(화면) · `scripts/cart-talk-check.ts`(말 100문장)
> 단계마다 **새 시크릿 탭**에서 시작 (장바구니가 3시간 남아 있어서). 첫 화면 동의에서 **주문 기록 저장**을 켜고 [이대로 시작].
> 결과 칸에는 **성공 / 실패 / 미확인** 중 하나만. 실패면 보인 것 한 줄 + 화면 캡처.

## 진행 순서 (한눈에)

| 순서 | 확인할 것 | 대략 |
|---|---|---|
| 1 | [담기] → 계속 고르기 · 위 🛒 개수 · 아래 "○○원 주문하기 N" | 1분 |
| 2 | 같은 것 두 번 → 한 줄 2개 · 수량 [−][+] · 하나만 따로 바꾸기 | 2분 |
| 3 | 새로고침해도 장바구니 그대로 · 주문하면 비움 | 1분 |
| 4 | "다 드실 거예요?" · [내 거] [같이 먹는 사람 거] · 그 사람 알레르기만 | 3분 |
| 5 | 말로 여러 개 ("든든한 거 하나 가벼운 거 하나 매운 거 하나" 등) | 3분 |
| 6 | "이거 하나 저거 하나" · "이거 두 개" | 1분 |
| 7 | 사람 ("나는 두 개 민수는 하나", "3명이야, 민수는 …") | 2분 |
| 8 | 한 줄 10개 · 5줄까지 · 한 사람 말은 그대로 | 1분 |

## 1. 담고 계속 고르기
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ③ 추천 카드의 버튼을 봄 | **[담기]** (전엔 [이걸로 고르기]) | |
| [담기] | 화면은 **③ 그대로**, "담았어요 · 장바구니 1개" 알림, 위 🛒에 빨간 **1**, 아래 **"○○원 주문하기 1"**, 카드에 "담음 1" | |
| 아래 "주문하기" 또는 위 🛒 | **⑥ 장바구니**로: 줄(메뉴·옵션 요약·[−] 1개 [+]·금액), 합계, [이대로 주문하기] | |
| 줄을 누름 | ④ 옵션에서 그 메뉴의 빵·소스 등을 고침 | |

## 2. 수량
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 같은 카드 [담기]를 한 번 더 | 줄은 그대로 하나, **2개**, 🛒 2, "담음 2" | |
| 장바구니에서 [+] / [−] | 개수·금액·🛒·아래 금액이 같이 바뀜. 1개에서 [🗑]이면 그 줄 빠짐 | |
| 2개짜리 줄을 눌러 ④ 위를 봄 | "2개 모두 바뀌어요" + **[하나만 따로 바꾸기]** → 누르면 1개 + 1개 두 줄로 | |

## 3. 남아 있기·비우기
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| 2줄 담고 새로고침 | 🛒 숫자·줄 그대로 | |
| [이대로 주문하기] → [확인] | 주문서 글(2개 이상이면 맨 위 "모두 ○개 · 참고 합계"), 내 주문 기록 | |
| 다시 [담기] | 새 장바구니 (🛒 1부터) | |

## 4. 같이 먹는 사람
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ②에서 알레르기 **우유** → 두 메뉴 [담기] | 장바구니에 **"다 드실 거예요?"** | |
| [같이 먹을 사람 것도 있어요] → 2번 줄 누름 | ④ 위 "누구 거예요?" **[내 거] [같이 먹는 사람 거] 두 개만** (사람 늘리는 버튼 없음), 2번 줄엔 우유 경고 없음 | |
| "같이 먹는 사람 알레르기" 열고 **땅콩** | 그 줄만 땅콩. 메뉴 하나 더 담고 그 줄에서 **[앞 줄 사람과 같아요]** → 땅콩 복사 | |
| [이대로 주문하기] → [확인] | 글에 "1번 · 나"(우유), "2번 · 같이 먹는 사람"(땅콩)이 따로, "내 것 1줄만, 같이 먹는 사람 것 ○줄은 안 남겨요" | |

## 5. 말로 여러 개
| 말 (②에 입력 또는 🎤) | 기대 결과 | 결과 |
|---|---|---|
| `든든한 거 하나 가벼운 거 하나 매운 거 하나` | 장바구니 3줄 (아직 안 고름), ③ 위 "1번: 든든한 거 · 2번: 가벼운 거 · 3번: 매운 거", [담기]마다 다음 줄 추천으로 | |
| `든든한거 한개랑 가벼운거 한개` | 2줄 (든든한·가벼운 따로) — 오늘 오전에 하나만 나오던 것 | |
| `매운 거랑 안 매운 거 하나씩` | 2줄 (매운 쪽·안 매운 쪽) | |
| `하나는 해장할 거, 하나는 가벼운 거` | 2줄, 해장 줄엔 수프 세트 | |
| `잠봉, 치킨, 스파이시` | 1번 잠봉 담김, 2·3번 고르기 (치킨 메뉴·매운 메뉴 추천) | |
| `로스트 치킨 2개` → `전부 토마토 빼` | 한 줄 2개 → 토마토 빼기 | |
| 규칙에 없는 말투 `배고픈 사람 거 하나랑 다이어트 중인 사람 거 하나 줘` | 2줄 (든든한·가벼운). 규칙이 못 나누면 AI가 나누고 "AI가 여러 개로 나눴어요" | |

## 6. 이거·저거
| 말 | 기대 결과 | 결과 |
|---|---|---|
| ③이 보일 때 `이거 하나 저거 하나` | ③ **1번·2번** 추천이 담김 | |
| `이거 두 개` | ③ 1번 추천 **2개** | |

## 7. 사람
| 말 | 기대 결과 | 결과 |
|---|---|---|
| `나는 두 개 민수는 하나` | 1번 · 나 (2개) · 2번 · 민수 | |
| `3명이야, 민수는 매운 거 못 먹고 지은이는 새우 알레르기` | 1번 나 · 2번 민수 · 3번 지은, 민수 추천엔 스파이시 없음, 지은 줄 알레르기 (새우) | |
| `민수 거 소스 빼 줘` | 민수 줄만 소스 없음 | |
| `한 명 더 와` | 같이 먹는 사람 줄 하나 더 + 그 줄 추천 | |

## 8. 최대·한 사람 말
| 말 / 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| `로스트 치킨 12개` | 10개 + "한 줄에 10개까지" | |
| 다른 메뉴를 계속 [담기] | 5줄이 되면 "5줄까지" 안내, [+ 메뉴 더 담기] 없음 | |
| `로스트 치킨 먹을 건데 양파 빼고 피클 추가, 우유 알레르기` | 1줄 (나뉘지 않음) | |
