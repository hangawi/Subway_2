# 10/27 장바구니·사람별 주문 검수 시나리오

> 주소 **https://subway.metasolveai.com** · 10/27 예형님 11가지 반영 · 자동 점검: `scripts/cart-check.ts`(화면 57) · `scripts/cart-talk-check.ts`(말 100) · `scripts/odd-cart-check.ts`(예상 밖 말 100)
> 단계마다 **새 시크릿 탭**에서 시작해요. 장바구니가 3시간 남아 있어서예요. 첫 화면 동의에서 **주문 기록 저장**을 켜고 [이대로 시작]을 눌러요.
> 결과 칸에는 **성공 / 실패 / 미확인** 중 하나만 써요. 실패면 보인 것 한 줄과 화면 캡처를 남겨요.
> 바뀐 것: ⑤ 장바구니 → ⑥ 주문서 순서, 사람마다 버튼(나 · 같이 먹는 사람 1·2), [담기] 뒤 [다음 사람 고르기], 사람별 버튼 색(초록·빨강), "다 드실 거예요?"는 ② 아래, 주문서는 주문할 때만·메뉴마다 사진, 줄 이름 짧게, 장바구니 말은 규칙 → 젬마 → OpenAI

| 2 | 3명: 사람마다 추천 · 빨강/초록 · [담기] 뒤 옵션 고르고 [다음 사람 고르기] | 3분 |

## 1. 순서·주문서
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ③에서 아무 메뉴 [담기] 후 아래로 내려 봄 | ④ 옵션 고르기 → **⑤ 장바구니**. **⑥ 주문서는 아직 안 보임** | |
| ④ 맨 아래를 봄 | 참고 금액·열량, 알레르기 경고나 "아직 안 고른 것"이 있으면 여기 | |
| ⑤에서 [이대로 주문하기] | **⑥ 주문서**가 열림: 담은 메뉴 사진, 옵션, 금액, "이 주문서로 주문할까요?" [다시 고르기] [확인] | |
| [다시 고르기] | ⑥이 닫히고 ⑤ 장바구니로 | |
| 아래 초록 "○○원 주문하기" 버튼 | 바로 ⑥ 주문서 | |

## 2. 3명이서 (사람마다 따로)
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ②에 "3명이야" | ③ 위에 **1번: 나 · 아직 / 2번: 같이 먹는 사람 1 · 아직 / 3번: 같이 먹는 사람 2 · 아직**, 셋 다 **빨강** | |
| 1번 추천에서 [담기] | **③은 그대로 1번**, ④에서 1번 옵션·세트를 고를 수 있음, 1번 버튼이 **초록 ✓ 고름** | |
| ④ 맨 아래 | "나 것을 다 골랐으면 눌러 주세요" + **[다음 사람 고르기 · 2번 같이 먹는 사람 1]** | |
| [다음 사람 고르기] | 위 ③으로 올라가 **2번 사람 추천**, ④는 닫힘 | |
| 2번·3번도 같은 방법 | 마지막엔 버튼이 **[다 골랐어요 · 장바구니 보기]**, 세 버튼 모두 초록 | |

## 3. 한 사람이 두 개
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| "3명이야" → 1번에서 [담기] → **다른 메뉴 [담기]를 한 번 더** | ⑤ 장바구니에 **1번 · 나, 2번 · 나** (두 줄 모두 나), 2·3번 사람 줄은 그대로 "아직 안 고름" | |
| 같은 메뉴 [담기]를 또 | 그 줄이 **2개** (한 줄 수량) | |
| 새 탭에서 "나는 두 개 먹을 거야" | 1번 · 나 줄 하나 (2개), 추천에서 고르면 그 메뉴 2개 | |
| "나는 두 개 민수는 하나" | 1번 · 나 (2개) · 2번 · 민수 | |

## 4. 누구 거예요? (3명 모두)

|---|---|---|
| 3명 다 고른 뒤 2번 줄을 누름 | ④ 위 "누구 거예요?"에 **[내 거] [같이 먹는 사람 1 거] [같이 먹는 사람 2 거] [+ 다른 사람]** | |
