# 10/27 오후 검수 시나리오: 젬마 먼저 · 사람별 묶음 · 장바구니 화면

> 주소 **https://subway.metasolveai.com** (cc0a329) · 같은 날 오전 시나리오([10-27_장바구니_사람별_검수_시나리오.md](10-27_장바구니_사람별_검수_시나리오.md))를 대신해요.
> 단계마다 **새 시크릿 탭**에서 시작해요. 결과 칸에는 **성공 / 실패 / 미확인** 중 하나만 써요. 실패면 보인 것 한 줄과 화면 캡처를 남겨요.
> 바뀐 것
> - 모든 말을 **젬마가 먼저** 알아들어요. 규칙은 검사와 비상용이에요.
> - 사람마다 묶어서 보여요. 장바구니, ③ 사람별 추천, ④ "누가 먹어요?" 모두요.
> - **장바구니 화면이 옆에서 열려요.**
> - [담기]를 누르면 ④로 내려가요.
> - 10명까지 담을 수 있어요.

## 1. 장바구니 화면
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| ③에서 [담기] | **④ 옵션 고르기로 내려감**, 아래 버튼이 "○○원 · 장바구니 보기 · 1" | |
| 아래 [장바구니 보기] (또는 위 🛒) | **옆에서 장바구니 화면이 열림**: 맨 위 [←] 장바구니, ⑤ 장바구니 | |
| [이대로 주문하기] | 같은 화면 아래에 **⑥ 주문서** (메뉴마다 사진) + [다시 고르기] [확인] | |
| [←] 또는 휴대폰 뒤로 가기 | 장바구니 화면이 닫히고 주문 화면 그대로 | |
| 장바구니 화면에서 줄을 누름 | 화면이 닫히고 ④에서 그 줄 옵션 | |

## 2. 사람별 묶음
| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| "나는 소고기 하나랑 돼지고기 들어간 거 해주고 둘 다 맵게 해줘 그리고 친구는 치킨에다가 제로콜라로" | ③ 위 **나**: 1번 쇠고기·매운 거, 2번 돼지고기·매운 거 / **친구**: 3번 닭고기 + 코카콜라 제로 (모두 빨강) | |
| 사람마다 [담기] → ④ 아래 [나 다음 메뉴 고르기]·[다음 사람 고르기 · 친구] | 고른 칸은 초록, 메뉴 이름으로 바뀜 | |
| 장바구니 화면 | **나 · 2개 · ○○원** 아래 1번·2번, **친구 · 1개** 아래 3번 (친구 줄에 코카콜라 제로) | |
| ④ "누가 먹어요?" | [나 · 고른 메뉴들] [친구 · 고른 메뉴] [+ 사람 추가] | |
| 친구 줄에서 [나]를 누른 뒤 다시 봄 | 버튼에 **친구가 그대로 남아 있음** | |

## 3. 젬마가 알아듣는 말
> 결과 아래 "젬마가 나눠 알아들었어요"가 나오면 젬마가 처리한 거예요. 한 번에 2~10초쯤 걸려요.

| 하는 일 | 기대 결과 | 결과 |
|---|---|---|
| "야구부 5명이서 매운 걸로 소고기 들어간 걸 먹으려고 하는데 3명은 제로콜라 2명은 일반 콜라로 해주고 하나는 토마토 빼줘" | 5명 (나 + 같이 먹는 사람 1~4), 모두 든든·쇠고기·매운 거, 3명 제로콜라(그중 1명 토마토 빼기), 2명 콜라 | |
| "감기 걸렸는데 그거에 맞게 추천해줘" | "이렇게 이해했어요: 감기라서 …", ③ AI 한마디가 **감기에 왜 맞는지** (예: 자극이 적고 …) | |
| "한 명은 매운 거랑 든든한 거 하나씩, 한 명은 가벼운 거에 토마토 빼주고, 한 명은 소고기에 제로콜라, 한 명은 두 개 시키고 나머지 두 명은 각각 하나씩" | 사람 6명, 8줄 (첫 사람 2줄, 두 개 시킨 사람 2줄) | |
| "야구부 11명인데 든든하게" | 10명만 담고 "한 번에 10명(10줄)까지예요" | |
| "로스트 치킨 양파 빼고 하나" | 지금처럼 한 사람 주문 (④로 바로) | |
| (말이 아주 길 때) | 40초가 넘으면 "젬마 답이 늦어요. 잠시 뒤 다시 말해 주세요" — 엉뚱한 빈 줄이 생기지 않음 | |
