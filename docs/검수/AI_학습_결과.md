# AI 학습 결과

> 10/20 예형님 결정 (김민지님 협의 완료). 학습한 AI는 **예형님 확인 전까지 실제 손님 답에 쓰지 않음** — 지금 서비스는 그대로 규칙 → A100 gemma → OpenAI.

## 학습 1번 (10/20 밤)

### 어떻게 했나

| 항목 | 내용 |
|---|---|
| 서버 | A100-SXM4-80GB (runyour.ai, 계정 ruai-u5000 — SOPHIA와 같이 씀). 읽기만 확인: 사용 67GB(지금 gemma vllm 57GB + 다른 프로그램 10GB), 남은 약 14GB |
| 모델 | gemma 31B에 붙이려면 25~35GB 필요 → gemma를 멈춰야 해서 안 함. 계획대로 **작은 모델 Qwen2.5-1.5B-Instruct + LoRA** (메뉴·재료는 이름으로 내게 학습, 쓸 때 코드가 id로 바꿈) |
| 자리 | `~/subway-train` 폴더 안에서만 (가상환경·모델 파일 포함). 기존 gemma·다른 계정 프로그램은 안 건드림 |
| 학습 자료 | 1차+2차 **5,817문장** → 지금 AI가 내는 모양의 JSON (정답 = 규칙 결과, 1·2차에서 정답 표와 100% 같음) — `scripts/train-data.ts` |
| 시험지 | 학습에 안 쓴 **1,000문장** (2차 틀 + 다른 난수, 같은 문장 없음) — 시험지 파일은 10/22에 지움 (다시 만들기: `npx tsx scripts/train-data.ts`) |
| 학습 | 2문장 × 4번 모으기, 2바퀴(1,455번 반영), **47분**, GPU 최대 **5.7GB** (상한 8GB). 첫 시도(8문장씩)는 상한 12GB에 걸려 스스로 멈춤 — 다른 프로그램 영향 없음 |
| 서비스 영향 | 학습 내내 vllm(gemma) 그대로, 실제 주소 AI 해석 정상, **OpenAI 기록 6번 그대로**(늘지 않음) |

### 결과 (같은 시험지 1,000문장, 규칙 없이 AI만)

| | 완전 일치 | 칸별 맞음 | 지어낸 칸 | 놓친 칸 | JSON 형식 |
|---|---|---|---|---|---|
| **학습한 작은 모델 (1.5B)** | **96.4%** (엄격하게) | 99% 넘음 | 15 | 22 | 1,000/1,000 |
| 학습 안 한 같은 작은 모델 | 0.1% | — | 211 | 265 | 180/1,000 |
| 지금 gemma 31B (너그럽게: false=null) | 16.1% (메뉴 빼면 20.7%) | 88.5% | — | — | 988/1,000 |

- gemma가 낮은 이유: 메뉴가 이름 없이 번호(menu_1234)로만 주어져 엉뚱한 메뉴를 고름("피자썹 ㄱㄱ" → 쿠키), 말에 없는 종류·메인 재료·"왜?"를 붙임. 지금 서비스는 이걸 규칙과 "말에 없는 건 버림" 장치로 막고 있음 (그래서 실제 주소 정확도는 100%)
- 학습한 모델이 틀린 곳: 빵(97.7%), 세트 구성품(99.2%)
- 주의: 정답이 규칙 결과라, 학습한 모델은 규칙의 말버릇까지 배운 것 — 규칙이 처음 보는 말투(3차)에서 진짜 실력이 드러남 → **3차 문장으로 다시 비교**

### (1번 뒤 계획이었던 것)

- 3차(10/21 09:00): 3차 문장으로 학습 전 gemma vs 학습 1번 비교 → 학습 2번(1+2+3차 9,000문장) → 시험지로 최종 비교
- 실제로 바꿀지(⑤)는 예형님 확인 뒤 — 바꾸면 순서는 규칙 → 학습한 AI → gemma → OpenAI, 처음엔 몰래 써 보기(기록만)

## 학습 2번 (10/21 오전) + 3차 문장 비교

| 항목 | 내용 |
|---|---|
| 학습 자료 | 1+2+3차 **8,733문장** (같은 작은 모델 1.5B + LoRA, 2바퀴 2,184번 반영, 약 58분, GPU 최대 5.7GB) |
| 3차 비교 문장 | 3차 문장 1,000개 (사투리·수다·질문 섞기·애매한 말) — 학습 1번은 한 번도 못 본 말투 |
| 서비스 영향 | 없음. OpenAI 6번 그대로. gemma 3차 시험이 써브웨이 배포로 한 번 끊겨 다시 돌림 |

### 결과 (규칙 없이 AI만, 완전 일치)

| 모델 | 시험지 1,000 (2차 틀, 학습에 안 씀) | 3차 1,000 (처음 보는 사투리) |
|---|---|---|
| 지금 gemma 31B | 6.5% (너그럽게 16.1%) | 1.7% (너그럽게 10.6%) |
| 학습 1번 (1·2차) | 95.5% | **66.7%** |
| 학습 2번 (1·2·3차) | **96.6%** | 96.4% ⚠ 3차를 배웠으니 외운 점수 (공정한 비교 아님) |

- 학습은 **배운 말투엔 아주 강하고, 처음 보는 말투엔 많이 떨어짐** (1번: 2차 틀 95.5% → 3차 사투리 66.7%). 규칙도 3차 처음 67.7%였으니 처음 보는 말투엔 둘 다 비슷한 수준
- 지금 서비스(규칙이 99% + 규칙이 못 읽은 것만 gemma, 지어내기 막기)는 1·2·3차 실제 주소 모두 100%
- 학습 2번의 진짜 실력(처음 보는 말투)은 **4차**(예형님이 실제로 쓴 말투)로 봐야 함
- 바꿀지(⑤ 몰래 써 보기)는 예형님 결정 — 바꿔도 이득은 "규칙이 못 읽은 약 1% 문장"에서만
