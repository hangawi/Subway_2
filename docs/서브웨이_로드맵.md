## 사용 흐름

```text
앱 열기
  │
  ▼
① 지금 시간  ── 앱이 알아서: "화요일 12:10 → 점심"
  │
  ▼
② 지금 위치  ── 위치 허용 → 강남역 / 거부하면 "강남역" 직접 입력
  │
  ▼
(말하기, 선택) "만 원 이하, 단백질 많이, 매운 거 빼고"
  │      → AI는 말을 조건으로 바꾸기만 함: 예산 1만, 단백질 우선, 매운맛 제외
  ▼
③ 근처 써브웨이  ── 카카오로 주변 써브웨이 매장 찾기
  │                → 지금 영업 중인지 확인 → 닫은 매장 제외
  │                → 가까운 매장 1곳 + 다른 매장 2곳 ("걸어서 5분, 지금 영업 중")
  │
  ▼
   메뉴 Top3     ── 엔진이 영양·예산·알레르기·취향으로 판단 → 메뉴 카드 3개 + 이유
  │                → "빵은 위트로, 소스 빼 줘"로 옵션 수정
  │                → 주문서 완성 (메뉴·크기·빵·치즈·야채·소스·가격·영양)
  ▼
④ 주문      ── 주문서 확인 → [확인]을 눌러야만 보냄
  │            → 먼저: 주문서 복사·매장 전화·지도 열기로 넘겨주기
  │            → 나중: 매장에 자동 접수
  ▼
⑤ 결제      ── (무기한 연기) 결제 → 결과 확인 → 필요하면 취소·환불
  │
  ▼
기록        ── "이걸로 주문했어요" → 다음엔 "지난번처럼"
```

## 0. 이 프로젝트는

**지금 시간과 내 위치를 보고, 근처 써브웨이 매장과 나에게 맞는 메뉴를 골라 주고, 주문·결제까지 이어 주는 앱**이다.
회사의 공통 판단 엔진(**김민지 SOPHIA Decision Graph**)을 음식 분야에 처음 적용한다. 엔진은 새로 만들지 않고, 써브웨이용 판단 규칙(어댑터)만 붙인다.

### 판단 원칙
- **판단은 엔진이 한다.** AI는 말을 조건으로 바꾸기만 하고, 순위·실행을 정하지 않는다.
- **안 되는 건 먼저 거른다.** 영업 안 함·너무 멂·예산 초과·알레르기·뺀 재료가 있으면 제외하고 이유를 남긴다.
- **같은 입력이면 같은 결과.**
- **승인 없이는 주문·결제를 하지 않는다.**
- **확인 안 된 수치는 확인 안 됐다고 보여 준다.** 추정 영양값을 공식값처럼 보여 주지 않는다.

### 2-2-1. 알레르기 계산 방식 (10/13에 바꿈)

- **문제 (10/8 확인):** 메뉴 통째로 알레르기를 보고, ★(포함 가능)까지 빼면 우유 알레르기는 메뉴 1개, 대두·토마토는 0개만 남는다. 메뉴 알레르기에 기본 야채·위트빵이 섞여 있어서, 토마토를 빼고 주문해도 "토마토 포함"이 된다.
- **바꿀 방식:** 고른 재료(메인 + 빵 + 치즈 + 야채 + 소스 + 토핑)의 알레르기를 합친다. ● 포함은 뺀다. ★ 포함 가능은 빼지 않고 "포함 가능" 경고와 함께 보여 준다.
- 공식 표에 없는 재료가 들어가면 "알레르기 확인 필요"로 표시한다.
- 🆕(10/15 점검) **그대로 둔 기본 재료(위트빵·기본 야채 8종)의 알레르기도 합친다** (샌드위치만). 공식 메뉴 줄에 위트빵의 ★(우유·난류)가 빠진 메뉴(로스트 치킨 아보카도)가 우유 알레르기 추천 1위로 오르던 문제. 다른 샌드위치 26개는 결과 그대로. `subway.menu@0.7`
- 🆕(10/15) **옵션 화면에도 표시:** 고른 알레르기가 든 재료는 빨간 바탕 + "우유 들어 있음", ★는 "우유 ★", 정보 없는 재료는 "알레르기 확인 필요". 막지는 않는다(피하고 싶은 것일 수도 있어서). 그래도 넣으면 주문서 위에 빨간 경고, ★면 노란 경고. 주문서 글에는 "※ 우유 알레르기가 있어요. 재료 확인 부탁드려요" 줄

> "평소 소고기 좋아함"(평소 취향)과 "오늘은 소고기 피하고 싶음"(오늘 상태)을 **따로 보존**하고, 각 앱은 최신·유효한 상태로 판단한다.
> 10/20 기준 SOPHIA에 **이미 있는 것**: 계정(패스키·복구·앱 사이 이어받기 `services/identity/`), 감정 상태와 허용 확인(`state/emotion/`). **없는 것**: 다른 주소(subway)에서의 로그인, 음식 취향 저장, 평소/오늘 구분, 음식 추천 목적.

           ◀──── 쓰기: 늘 뺀 야채, "오늘은 소고기 피함" ── (동의 범위 안)
