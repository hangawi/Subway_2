# 메뉴·가격이 바뀌었을 때 (로드맵 50번, 10/19)

써브웨이가 새 메뉴를 내거나 가격·영양·알레르기가 바뀌면 이 순서대로 해요. 개발자가 아니어도 할 수 있게 적었어요.
**한 번에 한 가지씩, 확인하고 다음으로** 넘어가요. 중간에 이상하면 멈추고 개발자에게 물어요.

## 언제 하나요
- 써브웨이 공식 홈페이지(subway.co.kr)에 새 메뉴가 보이거나, 매장 가격이 바뀌었다는 소식이 있을 때
- 한 달에 한 번은 확인 (예: 10/19 기준 공식 홈페이지에 **"램 & 후무스", "램"** 이 새로 보임 — 아직 우리 메뉴판에 없음)

## 준비
- 이 컴퓨터에 `Subway_vol2` 폴더, VS Code, 인터넷
- 터미널(VS Code 아래쪽)을 열고 `Subway_vol2` 폴더에서 시작해요

## 순서

| # | 할 일 | 명령 | 확인할 것 |
|---|---|---|---|
| 1 | 공식 메뉴·재료·영양 받기 | `npx tsx scripts/fetch-official.ts` | 마지막 줄 `menus 숫자 (nutrition 숫자), ingredients 숫자` — 숫자가 지난번보다 크게 줄었으면 **멈춤** (홈페이지 모양이 바뀐 것) |
| 2 | 공식 가격 받기 | `npx tsx scripts/fetch-prices.ts` | `data/입력표/가격.csv` 의 빈 칸이 채워짐. **이미 채운 칸은 안 바뀜** → 가격이 바뀐 메뉴는 3번에서 직접 고침 |
| 3 | 사람이 고칠 것 고치기 | 엑셀로 `data/입력표/가격.csv` 열기 | 새 메뉴 가격·바뀐 가격을 고치고, "확인한 곳"·"확인한 날"을 적어요. 30cm가 없는 메뉴는 30cm 칸을 비워 둬요 |
| 4 | 알레르기 표 (바뀌었을 때만) | 공식 홈페이지의 알레르기 표 그림을 `data/official/allergy_img.png` 로 바꾼 뒤 `python scripts/read-allergy-image.py` | 실패하면("줄 수가 다름") 새 메뉴 줄이 생긴 것 → **개발자에게** (줄 이름을 더해야 함) |
| 5 | 메뉴판 만들기 | `npx tsx scripts/build-catalog.ts` | 끝에 경고가 나오면 읽어 봐요 (이름이 연결 안 된 메뉴 등) |
| 6 | 메뉴 사진 (새 메뉴가 있을 때) | `npx tsx scripts/fetch-menu-images.ts` | `사진 없음 N개` 에 새 메뉴가 없어야 함 |
| 7 | 시험 | `npm run verify` | 마지막에 `Tests N passed`, 실패 0. 실패하면 **멈춤** (어떤 시험이 실패했는지 개발자에게) |
| 8 | 눈으로 확인 | `npm run dev` 후 휴대폰 크기 화면에서 새 메뉴·가격 | 새 메뉴 카드·사진·가격·알레르기 표시 |
| 9 | 올리기 (배포) | 커밋 후 `git push` | main에 올리면 자동 배포. 2~3분 뒤 https://subway.metasolveai.com/health 의 commit 이 방금 것인지 |

## 하면 안 되는 것
- 공식 자료에 없는 값을 짐작으로 넣지 않아요 (가격·영양·알레르기). 모르면 비워 두면 화면에 "확인 필요"로 나와요
- 알레르기 표는 **사람이 그림과 한 번 더 대조**해요 (`data/입력표/알레르기표.csv`) — 틀리면 위험해요
- 김민지 운영 인수·SOPHIA 점검 시간에는 배포하지 않아요

## 문제가 생기면
- 배포 뒤 이상하면: 서버가 지난 버전(`subway-app:prev`)으로 자동으로 되돌리기도 해요. 직접 되돌리려면 앞 커밋으로 `git revert` 후 다시 올려요
